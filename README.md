# Nexo Digital

Abra esta pasta no Codex ou no Claude Code.

Para iniciar, anexe o briefing e peça: use scaff-iniciar e leia contexto/PROJETO.md.
Para retomar, peça: use scaff-retomar e leia contexto/HANDOFF.md.
Para a equipe de agentes conduzir as fases, peça: use scaff-orquestrar.
Pedidos prontos para cada situação: guia/prompts.md. Palavras técnicas: guia/glossario.md.
Guia do perfil inicial web: playbook/stacks/web.md.

Confira a configuração com python scripts/verificar.py e as skills e os agentes com
python scripts/sincronizar_skills.py --check.
